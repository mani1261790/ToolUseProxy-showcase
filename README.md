# ToolUseProxy 展示資料

SecHack365の展示で使うデモ動画、公開用に整理した保存ログ、チラシ・ポスターのPDFです。

**公開ページ:** https://mani1261790.github.io/ToolUseProxy-showcase/

- `index.html`: 展示の入口と3種類の送信実験へのリンク
- `screening.html` / `demo.mp4`: 無音のループ上映。iPadのSafariに対応したインライン再生と全画面表示
- `logs.html` / `viewer.js`: 2026年9月24日の保存ログと来歴グラフ
- `materials/handout.pdf`: 2026年9月25日修正版のチラシ（A4両面・2ページ）
- `materials/poster.pdf`: ポスター全体版（1ページ）
- `materials/poster-a3-print.pdf`: ポスター分割印刷版（A3縦・4枚貼り合わせ）

PDFはイベント用フォルダーの配布ファイルを内容・画質を変えずに掲載しています。

ログは40件の呼び出しと実際の判定結果を収録しています。内部メモ・スキルの参照を含む8件は、その呼び出し全体の入出力を省略しています。PC固有のパス、ローカル接続URL、実行時の内部メタデータも除いています。秘密のメモや手順書はデモ用の架空データです。

このサイトは静的な保存版です。ローカルのDBや稼働中のToolUseProxyへ接続しません。現行の製品・導入手順は [ToolUseProxy](https://github.com/mani1261790/ToolUseProxy) を参照してください。

GitHub Pagesは `main` ブランチのルートから公開します。動画を含むサイト全体は約14MBです。上映中の通信を避ける場合は、動画を端末へ保存して再生してください。
